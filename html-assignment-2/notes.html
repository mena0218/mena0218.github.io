List tags

Tags that are useful for containing information and items of texts. There are three types of lists in HTML such as an unordered list, ordered list and description list. Each list is defined by how they organize the information. They can be ordered, unordered or have a description based on needs or the context of the information. Unordered lists are used to list items, but the order doesn't matter like a list of items in pantries, equipment, potential travel destinations, likes and dislikes, etc. Ordered lists are used when the order of the information is important like a step-by-step process like following a recipe or listing favourite things or people from worst to best in order. Description lists are used to describe and specify items especially for terms that the general public need clarification on or to categorize items.

Quote tags
These tags or used to cite words that were used by a different source than from the user. The quote tag (q) is used to embed the quotation marks within other elements and tags like the paragraph tag (p). To create a standalone quote from other elements in text, the blockquote tag (blockquote) is used to highlight a quotation. In addition, the cite tag is used as well to emphasize the source of the quote itself.

Anchor tag
These tags help to link sources and other websites to each other and countless other ressources throughout the internet like images, documents or specific pages. They use an anchor tag (a) and href attribute [href] to provide the location of where it will link up to. For the link itself to open a new tab, use the attribute [target="blank"]. The anchor tags can even link to information that are on the page itself by using the hashtag [#], along with any specified words or descriptions, and linking it with another tag that contains the identical id attribute.
